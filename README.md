# PC Build Simulator 🖥️🔧

PC Build Simulator, oyuncuların bir bilgisayar anakartı üzerine donanım parçalarını sürükleyip bırakarak montaj yapmasını sağlayan 2D mobil simülasyon oyunudur. 

![Ekran Görüntüsü](placeholder_image_path.png)

## Özellikler
- **Gerçekçi Montaj Mekanikleri:** Mandalları açma, kilitleme, bileşen takma.
- **Etkileşimli Mini Oyunlar:** Termal macun sürme, fan vidalama ve daha fazlası.
- **Detaylı Parça Yönetimi:** CPU, GPU, RAM, M.2 SSD ve PSU kabloları.
- **Başarı Hissi:** Tüm parçalar tamamlandığında BIOS boot ekranı deneyimi.
- **Mobil Odaklı:** iOS ve Android cihazlar için optimize edilmiş sürükle-bırak kontrolleri.

## Teknolojiler
- **Oyun Motoru:** [Godot Engine 4.3](https://godotengine.org)
- **Programlama Dili:** GDScript (Tip güvenli)
- **Renderer:** Compatibility (OpenGL 3)
